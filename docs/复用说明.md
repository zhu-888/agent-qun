# 复用了什么，来源和许可证

调研日期：2026-11-13。三个仓库都克隆下来读过源码；下面写的是实际读到的情况，不是 README 的宣传语。

结论：**没有直接拿任何一个当底座，也没有复制它们的代码**。工作台是用 Node.js 自带模块新写的（不需要 `npm install`），借的是三者的做法。原因见每一节。

## zuiho-kai/bothouse（Apache-2.0，Go + 一部分 Node）

- **是什么**：把 Claude Code、Codex、DeepSeek Harness 等拉进一个群聊，由“组长 AI”分活。
- **为什么不当底座**：
  - 它的主程序是一个约 24 万行的 Go 桥接程序，围绕 Discord、飞书、QQ 这些聊天平台设计。
  - 仓库里唯一的三栏聊天页（`dsh/collab`）是 DeepSeek Harness 的插件，必须跑在 DeepSeek Harness 的网页宿主里，不能独立启动。
  - “团队桌面”（`/collab/desk`）只是只读的状态页，不能聊天。
- **借鉴了什么**：
  - 成员之间连续接力要有上限，超过就停下来提醒人（它默认 6 次；这里默认 12 次，可在设置里改）。
  - 同一条触发消息对同一个成员只建一条任务（它用 `UNIQUE(member_id, trigger_id)`；这里是 `UNIQUE(target, dedupe_key)`）。
  - 代码块和行内代码里的 @ 不算点名（这里另外把引用行也排除了）。
  - 启动 Claude 命令行前要去掉 `CLAUDECODE` 一类环境变量，否则它会以为自己嵌套在别的会话里。
  - Codex 续接会话时不接受 `--cd` 和 `--sandbox`，要改用工作目录和 `-c sandbox_mode=...`。
  - 额度用尽的识别方式（Claude 的提示语里有 “hit your … limit”）。
- **后来采用的**：运行中插话。它给 Claude 用流式输入（`--input-format stream-json`），给 Codex 用 app-server 的 `turn/steer`。这两条路我先各写了一个探测脚本对着真实命令行验证，再接进工作台（`server/agents/claude.mjs`、`server/agents/codex.mjs`）。它给 DeepSeek Harness 做插话靠的是自己带的一个扩展，原版 DeepSeek Harness 没有，所以 DeepSeek 没接。

## dichovsky/crew（MIT，TypeScript）

- **是什么**：让几个终端里的编码 Agent 通过项目内的 SQLite 收件箱协作，任务必须经过独立审查才算完成。
- **为什么不直接装**：
  - 它要求 Node.js 24.15 以上，并且启动时会强制检查；本机装的 Node.js 版本比这个低。
  - 它只有命令行，没有可以在程序里调用的入口。
  - 它假定用 tmux 和一个转发进程来唤醒成员，和这里“工作台直接启动真实 CLI”的方式不一样。
- **借鉴了什么**（`server/tasks.mjs` 和 `server/store.mjs`）：
  - “提交”和“审查通过”是强制分开的两步。
  - 权限按任务卡上的角色定，不按成员身份定：只有负责人能接单和提交，只有审查人能给结论。
  - 每次状态变化都是一次带版本号的更新（版本对不上就拒绝），并且留一条不可改的过程记录。
  - 数据库用 CHECK 约束兜底，程序有 bug 也写不进非法状态。
  - 界面用服务器推送事件（SSE）通知刷新。
- **比它多做的**：
  - crew 允许审查人和负责人是同一个成员（只在提示词里劝阻）。这里在数据库和代码里都禁止。
  - crew 的提交只有一段文字说明。这里要求成果文件、运行或核对方法、测试证据三样齐全，并记录每个文件的版本（内容哈希）。
  - 增加了返工次数、交接上限和去重。

## steipete/CodexBar（MIT，Swift）

- **是什么**：菜单栏小工具，显示 Codex、Claude Code 等的用量。
- **借鉴了什么**（`server/quota.mjs`）：
  - Codex 额度：启动 `codex app-server`，用 JSON-RPC 调 `account/rateLimits/read`。这条路由 Codex 命令行自己处理登录，工作台不接触任何凭据。
  - Claude 额度：让 Claude 命令行自己执行 `/usage` 再读输出。CodexBar 默认走的是另一条路（从钥匙串读登录令牌去调一个未公开的接口），这里**没有**采用，因为那需要工作台读取你的登录凭据，还会反复弹钥匙串授权。
  - DeepSeek 余额：官方公开接口 `GET https://api.deepseek.com/user/balance`。
  - 数据要带来源和更新时间，过期要标出来。
- **没有安装 CodexBar 本体**：它的命令行工具可以直接输出 JSON，但那需要再装一个 app；上面三条来源已经够用。

## 许可证义务

Apache-2.0 和 MIT 的义务都针对“复制或分发它们的代码”。这里没有复制代码，所以没有需要随附的许可证文本或 NOTICE。本说明保留来源，方便以后核对。
